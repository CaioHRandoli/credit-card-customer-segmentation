<div align="center">
  <h2>Segmentação de Clientes para Cartão de Crédito</h2>
</div>

Segmentação de clientes utilizando K-Means (aprendizado não supervisionado) em dados de uso de cartão de crédito para identificar compradores VIP, usuários ocasionais e financiadores de saque.<br>

<h3>Tecnologias e Detalhes Técnicos</h3>

- **Linguagem de Programação**: Python
- **Ambiente**: Jupyter Notebook
- **Modelo de Aprendizado de Máquina**: K-Means (algoritmo de clusterização)
- **Bibliotecas**: pandas, numpy, matplotlib, seaborn and sklearn

<h3>Dataset</h3>

- **Autor**: Arjun Bhasin 
- **Link**: [Credit Card Dataset for Clustering](https://www.kaggle.com/datasets/arjunbhasin2013/ccdata)
- **Algoritmo utilizado**: K-Means (aprendizado não supervisionado)
